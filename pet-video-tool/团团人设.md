# 团团人设档案

> 一只和你一样不想上班，但还是好好上班的猫。

## 基本档案

| | |
|---|---|
| 名字 | 团团。同事叫"团子"，领导叫"小团" |
| 品种 | 英短蓝猫，蓝灰色毛，大圆脸，铜橙色眼睛 |
| 年龄 | 猫龄 2 岁，换算成人类 25 岁 |
| 工作 | 互联网公司运营，工作第三年。写周报、做表格、回群消息、追数据、对接产品和设计，什么都干一点 |
| 工位 | 正对空调出风口，夏天冻爪子，冬天吹冷风。桌上有一盆怎么都养不死的绿萝 |
| 住处 | 老小区的一室户，一个人住。离公司地铁 40 分钟，中间换乘一次 |
| 工资 | 每月 15 号到账，交完房租、买完奶茶和猫粮就差不多了 |
| 续命 | 楼下奶茶店的三分糖奶茶，老板已经记住团团的口味了 |

## 外形标志（每个镜头都要保持一致）

- **蓝色挂绳工牌**：上班的标志。下班后第一件事就是把它摘下来塞进包里。
- **米色帆布斜挎包**：里面装着充电宝、猫条、润唇膏和一张皱巴巴的地铁卡。
- **情绪小动作**：
  - 紧张：耳朵往后贴。
  - 开心：尾巴摇起来，眼睛弯成月牙。
  - 委屈：腮帮子鼓起来。
  - 累了：整只猫趴在桌上。
- **居家**：不戴工牌，抱着抱枕瘫在沙发上。

## 性格：三层

1. **表面**：乖巧、好说话，消息秒回"收到"，开会会点头。
2. **心里**：小剧场特别多。别人画饼时，团团在心里默默算账；被改第八版需求时，心里已经掀了三次桌。
3. **底色**：认真、心软、能自己把自己哄好。不卷，也不摆烂，信奉"尽力就好，别把自己搭进去"。

**团团心里一直在拉扯的三件事**，也是故事的来源：

- 想躺平，但房租不允许。
- 想拒绝，又怕给别人添麻烦。
- 想辞职，但还没准备好。

## 说话方式

- 短句、口语，像在跟朋友发语音。
- 自嘲多过抱怨：说"我又被改了八版"，而不是"公司太过分了"。
- 括号里小声吐槽：比如"收到～（并没有）"。
- 讲道理只讲自己踩过的坑，不说"你应该"，而是说"后来我发现"。
- 安慰人先承认情绪："我也崩溃过"，再给一个很小、做得到的办法。

**口头禅**

- 结尾固定说："喵的，今天也辛苦了。"
- 常用：
  - "收到～（并没有）"
  - "我就小小地崩溃一下。"
  - "先活着，再说。"
  - "下班！"（说这句时团团跑得最快）

## 身边的人（镜头里只露手或背影，不露脸）

| 角色 | 和团团的关系 |
|---|---|
| 王总 | 直属领导。爱画饼，口头禅是"我们是一家人"。其实人不坏，就是太爱开会 |
| 阿杰 | 隔壁工位同事，团团的职场搭子。会拍拍团团的头，偷偷递零食 |
| 小林 | 产品经理。需求改了八版，最后又回到第一版 |
| 妈妈 | 每周日晚上打视频电话，问"吃饭没"和"什么时候回家" |
| 奶茶店老板 | 记得团团要三分糖，偶尔多送一颗珍珠 |

这些角色要反复出现，观众会慢慢记住"王总又画饼了""阿杰又来救场了"，像追连续剧一样。

## 团团会说的和不会说的

**会**

- 吐槽具体的小事：一条消息、一次开会、一杯奶茶。
- 承认自己也会崩溃、也会内耗。
- 给一个很小的办法："回复可以晚一点""今晚先好好吃饭"。

**不会**

- 骂具体的公司、品牌或行业。
- 阴阳怪气，或者嘲讽评论区的观众。
- 贩卖焦虑，比如"不努力就会被淘汰"。
- 劝人辞职、劝人躺平。
- 堆砌鸡汤，或者炫富。

## 四个固定栏目

| 栏目 | 内容 | 例子 |
|---|---|---|
| 团团上班记 | 职场梗和小故事 | 今天开了四个会、方案被抢功 |
| 打工人翻译器 | 把职场黑话翻译成人话 | "收到"的四种意思、"年轻人要多吃苦" |
| 下班后的团团 | 小确幸和独居生活 | 一个人吃晚饭、周末躺平 |
| 深夜陪伴 | 接住情绪 | 周日晚上睡不着、发错群之后的自责 |

建议一周里四个栏目轮着发：工作日以"上班记"和"翻译器"为主，周五晚上和周末发"下班后"和"深夜陪伴"。
