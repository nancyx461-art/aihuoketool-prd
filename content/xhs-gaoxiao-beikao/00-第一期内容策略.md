# 第一期三篇与真实性核对

四篇各管一件事：第1篇看卷型，第2篇读公告，第3篇判公文，第4篇只解释四种用人方式。同一套清单不重复贴。

## 2026-10 核对后删掉或改口的内容

| 原来的写法 | 处理 | 依据 |
|---|---|---|
| 所有管理岗都先刷行测5000，只做言语、判断、资料 | 改成先看公告。省统考多偏公共基础；校招有的偏行测，有的不考行测 | 2025年校考回忆（有的卷明确不考行测）；统考与自主命题的科目差异 |
| 高等教育学只记学生管理和教学组织 | 改为《高等教育法》中的学校职责、学生权利义务；辅导员再看《普通高等学校学生管理规定》 | 2025年行政管理岗真题把高等教育法列为依据 |
| 近半年出现最多的六个话题 | 不再写成个人统计。行政岗写师德、服务教学科研、办文办会；辅导员另列心理、就业、安全 | 2025年真题回忆与面试回忆的常见范围，不是精确排行 |
| 面试就是把论述说出来；出分后几天就面 | 保留“间隔常常比较短”。补上结构化面试还有应急和人际，论述题集替代不了 | 2026年公告中的结构化面试说明 |
| 年龄常见30或35岁，按报名截止日算 | 改为以公告为准。硕士管理岗近年常见35或38周岁以下，辅导员往往更低 | 2026年武汉商学院、新疆工业学院等公告 |
| 备案制和事业编制并列，没有说明差别 | 写明总量备案制常见表述是“不纳入事业编制” | 2026年武汉商学院总量备案制公告 |
| 面试比例就是1:3或1:5 | 改为常见1:3，也有1:2、1:5 | 2026年多所高校公告 |
| 通知结尾只有“请遵照执行” | 改为“特此通知”和“请遵照执行”都可以 | 公文实践；笔试评分看文种和是否执行性语气 |
| 没提函，也没提日期格式 | 补上不相隶属用函；日期用阿拉伯数字、月日不补0 | 《党政机关公文处理工作条例》；GB/T 9704 |

个人经历没有改成另一段故事。不到三个月、大约一个月学习、符合条件就报、行测5000题集、校情与师德材料、公文模板、笔面共用题集，仍来自原来的备考分享。
