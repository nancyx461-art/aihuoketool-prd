# 高校备考小红书账号｜定位与内容矩阵

## 账号定位（一句话）

帮想进高校的人，用最短路径搞懂：投什么、笔试怎么准备、面试怎么答。

## 人设建议

- **身份**：高校行政/辅导员上岸人（或在备考中的复盘者）
- **语气**：务实、清单感、少鸡汤、多可执行步骤
- **差异点**：不只晒 offer，持续输出「题型拆解 + 模板 + 复盘」

## 主页设置

- **昵称示例**：高校上岸笔记 / 行政岗备考手账 / XX的高校求职日记
- **简介模板**：  
  高校行政｜辅导员｜管理岗  
  笔试框架｜公文模板｜面试题库  
  已整理：选择题考点 / 论述骨架 / 公文文种  
  评论区蹲模块，按需更新
- **背景图**：简洁大字「高校管理岗备考」+ 三个关键词（海投 / 笔试 / 面试）

## 前 7 篇内容节奏（冷启动）

| 顺序 | 笔记主题 | 目的 |
|---|---|---|
| 1 | 笔试备考经验总复盘（本系列 01） | 立人设、涨收藏 |
| 2 | 高校笔试到底考什么｜题型一张图 | 搜索流量 |
| 3 | 公文写作高频文种模板（通知/请示/报告） | 强收藏 |
| 4 | 校情校史怎么背才不崩 | 实用干货 |
| 5 | 笔面通用的 10 道高校热点论述 | 引流+互动 |
| 6 | 简历投高校行政岗，这 5 处最容易翻车 | 拓人群 |
| 7 | 面试自我介绍｜1 分钟版本怎么写 | 承接笔试后人群 |

## 标账号可学结构（不要照抄原文）

1. 开头用「时间线」建立可信度  
2. 中间用 1⃣️2⃣️3⃣️ 分步骤  
3. 笔试部分用 🌷 拆模块  
4. 结尾用心态收束 + 互动提问  
5. 标签覆盖：高校行政 / 管理岗 / 辅导员 / 笔试 / 面试
