# 厦门大学高校考编备考资料包（近3年考情版）

> **销售合规声明（必读）**  
> 1. 本包**不含**厦门大学官方原题，也不把文档站伪标题库冒充为「真题」。  
> 2. 凡标【模拟】的题目均为自编训练题，对标官方公布的考察方向。  
> 3. 凡标【可核验考情】的内容来自厦大人才招聘网 / 人事处公开通知。  
> 4. 凡标【校内经验题型】来自厦大公开求职分享（非当届原题）。  
> 5. 「考生真实回忆」专区当前为空：公开网络未能交叉核验到完整回忆卷。收到带年度/岗位的原帖后，按 `99-待核验回忆入库` 流程入库。

- 有 ≥2 条独立回忆交叉印证、且作者授权 → 迁入对应岗位「回忆辑」，仍标注「考生回忆，非官方原卷」。
