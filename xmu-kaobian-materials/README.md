# 厦门大学高校考编备考资料包（近3年考情版）

> **销售合规声明（必读）**  
> 1. 本包**不含**厦门大学官方原题，也不把文档站伪标题库冒充为「真题」。  
> 2. 凡标【模拟】的题目均为自编训练题，用于对标官方公布的考察方向。  
> 3. 凡标【可核验考情】的内容来自厦大人才招聘网 / 人事处公开通知。  
> 4. 凡标【校内经验题型】来自厦大公开求职分享（非当届原题）。  
> 5. 「考生真实回忆」专区当前为空：公开网络未能交叉核验到完整回忆卷。收到带年度/岗位的原帖后，按 `99-待核验回忆入库` 流程入库。

## 目录结构

| 目录 | 卖点定位 | 适用岗位 |
|------|----------|----------|
| `00-考情与声明` | 近3年官方考情对照、岗位分流、真实性标准 | 全员必读 |
| `01-学院公寓办辅导员` | 笔试（逻辑+公文+实务案例）+ 学校面试 + 实习考察 | 学院/公寓办辅导员 |
| `02-党政综合管理行政` | 笔试（逻辑+公文）+ 学校面试 + 用人单位面试 | 辅导员/综合管理类党政 |
| `03-业务岗附录` | 财务/外事/法务等（笔试同向，侧重单位面） | 业务管理岗 |
| `99-待核验回忆入库` | 小红书/微信回忆帖核验模板 | 产品迭代用 |

## 建议售卖拆册

1. **导员冲刺册** = `00` + `01`  
2. **行政冲刺册** = `00` + `02`  
3. **全岗合集** = 上述全部（封面必须写清：考情核验 + 模拟训练，非厦大原题）

## 更新原则

- 有 ≥2 条独立回忆交叉印证、且作者授权 → 迁入对应岗位「回忆辑」，仍标注「考生回忆，非官方原卷」。  
- 无法交叉印证 → 只进「线索池」，不上架为真题。
