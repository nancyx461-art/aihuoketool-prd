# 真实性标准与售卖红线

## 一、回忆帖入库打分（满分 5，≥4 才可标「考生回忆」）

| 分 | 条件 |
|----|------|
| 1 | 写明招聘年度 + 报考岗位（公寓办导员 / 综合管理党政 / 业务岗） |
| 1 | 考后约 7 日内首发，非二手搬运 |
| 1 | 题干具体（不只写「考了公文和逻辑」） |
| 1 | ≥2 个独立来源交叉印证关键题干 |
| 1 | 作者可联系且同意商用转载 |

## 二、红线（会导致售后与合规风险）

1. 把淘宝/文档站「厦大真题」公基单选题库当原题卖（与官方「逻辑+公文」考法不符）。  
2. 把厦门市事业编题冒充厦大校聘题。  
3. 导员卷与行政卷混装且不标注。  
4. 无来源地把碎片回忆拼成「完整试卷」。  
5. 未授权全文搬运小红书/微信帖。  
6. 封面写「原题/泄题/内部卷」等虚假宣传用语。

## 三、允许的诚实卖点话术

- 「近3年官方考情对照 + 岗位分流」  
- 「对标厦大公布考察方向的【模拟】笔试/面试训练」  
- 「校内公开分享提及的题型清单（非原题）」  
- 「经交叉核验的考生回忆辑（如有，单独成章）」
